# 智能资源版本 — 2026-10-18

- Gateway/Web：0.1.51
- macOS：0.1.41
- Connector：0.1.52
- iOS TestFlight：1.0.0，构建标签 8

## 变更

智能卡片采用随信附页样式，提供排版后的文档预览、紧凑图标操作，以及支持悬停、键盘聚焦
或触屏点击的补充说明。回复预览和 Workbench 继续共用资源与交互链路。

全局资源链接保留 Desk 文件身份和版本历史。用户私有的表单草稿支持跨设备恢复，并在并发
修改时提供明确的冲突处理。Web 和桌面端可在用户确认及设备策略允许后，请求指定 Connector
主机打开文件或执行 PTY 终端任务。这些设备动作需要显式开启，本次不包含原生 iOS 终端界面。

优化桌面设置和输入区导航，聊天与编辑器模块按需加载。升级构建依赖，包括保留隔离 Canvas
React 运行方式的 Babel 8 适配，以及 Vitest 5。

## 部署

先发布 Connector 0.1.52 二进制及签名更新清单，再部署生成新版 Connector 配置的 Gateway。
资源迁移 0104–0106 随 Gateway 启动执行。版本文件和发布检查通过后，再推送对应的 Gateway、
桌面端和 TestFlight 标签。
