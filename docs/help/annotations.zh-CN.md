# 频道批注

> [English](annotations.md)

文件批注和 Agent 执行事件批注共用一个独立面板。通过频道工具栏、Workbench
批注入口或事件行旁的批注按钮打开，可按当前对象、频道、文件、事件筛选和搜索。

- 文件批注保留整文件、文本、结构化路径和 inspectable URI 锚点。
- 在消息执行记录中对事件添加批注；Ctrl/Command+Enter 保存，Enter 换行。
- 展开批注可编辑、删除或定位来源。作者和频道管理员可修改；只读成员可以查看。
- 删除前在条目内确认。保存失败保留草稿；关闭未保存的编辑需要确认放弃。
- Send 将批注文字和文件/消息上下文加入消息草稿，用户检查后通过正常消息输入框发送。

两类批注统一保存在网关数据库的 `channel_annotations` 中，刷新页面、切换设备后仍然存在。
客户端每 15 秒刷新，并在修改后刷新。编辑和删除检查 revision，并发修改返回冲突，避免覆盖。
事件来源由网关验证，遵守事件 SEE 可见性策略；原始 trace 被清理后仍保留批注及来源快照。
来源文件改变导致锚点失效时，批注仍保留。

网关首次读取时自动导入现有频道 `annotations.yaml`，保留锚点和创建日期。导入幂等，删除后
不会重新出现；历史作者记为未知，由频道管理员管理。原 YAML 保留作为档案，新批注和修改
写入数据库。YAML 语法错误会显示提示，修复后刷新重试；无效单条记录跳过，原内容不会删除。

部署时通过迁移 `0103_channel_annotations.sql` 建表，需要重新构建并重新创建网关容器。
接口与回归测试运行方法见 [英文文档](annotations.md)。
