# Interactive resource release — 2026-10-18

- Gateway/Web: 0.1.51
- macOS: 0.1.41
- Connector: 0.1.52
- iOS TestFlight: 1.0.0, build tag 8

## Changes

Interactive cards now use a letter-enclosure layout with readable document
previews, compact icon actions, and contextual help available on hover, keyboard
focus, or tap. Reply previews and Workbench continue to share the same resource
and interaction path.

Global resource links retain Desk identity and revision history. Private form
drafts follow the signed-in user across devices, with explicit conflict recovery.
Web and desktop clients can request file opening and PTY terminal execution on a
selected connector host, subject to explicit approval and device policy. These
device actions remain opt-in; native iOS terminal surfaces are not included.

Desktop settings and composer navigation are improved, and chat/editor modules
load on demand. Build dependencies are updated, including Babel 8 with the
isolated Canvas React runtime preserved and Vitest 5.

## Deployment

Publish Connector 0.1.52 binaries and its signed update manifest before deploying
the gateway, whose generated connector configuration requires this version.
Resource migrations 0104–0106 run on gateway startup. Publish the matching gateway,
desktop, and TestFlight tags only after version metadata and release checks pass.
