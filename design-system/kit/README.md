# Editorial Correspondence — component kit

All 60 component types in [The Component Gallery](https://component.gallery/components/)
taxonomy, rendered in this repository's own design language. Generated by the
`ui-kit` skill and audited by it.

This is a **reference kit, not a second component library.** `frontend/src/components/ui/`
remains the implementation the app imports; this is the complete picture of the
style in one page — useful as a coverage map against
[INVENTORY.md](../INVENTORY.md), as a place to settle a visual question without
starting a dev server, and as a spec when a component that does not exist yet
has to be built.

## What is here

| Path | What it is |
|------|------------|
| `tokens.css` | The style. Channel values mirrored from `frontend/src/index.css`, scales from `tailwind.config.ts`. **The only file with raw values.** |
| `STYLE.md` | The twelve decisions in prose, plus the four places this kit deliberately departs from the repo and why. |
| `components/<id>.css` | One file per component. Every value resolves to a `--ui-*` token. |
| `ui.js` | Shared behaviour: overlay positioning, dialogs, roving focus, tabs, toasts, tree. Nine components share one overlay layer. |
| `gallery.html` | Preview **and** canonical markup — the source people copy from. |
| `BUILD.md` / `manifest.json` | The work plan and its state. |

## Viewing it

Open `gallery.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8000 --directory design-system/kit
```

The theme control at the top right flips between slate, paper and system. Dark
is the default, as in the product.

## Checking it

```bash
python3 ~/.claude/skills/ui-kit/scripts/audit.py --dir design-system/kit
```

It fails on missing implementations, stubs, raw colours that escaped
`tokens.css`, and components missing from the gallery; it warns on unfinished
specimens, hover without a focus treatment, and undemoed states.

## Keeping it honest

`tokens.css` is a mirror, not a fork. When `frontend/src/index.css` changes a
channel value, change it here in the same PR — the private `--_*` layer at the
top of the file is a one-to-one copy, so the edit is mechanical. If the two
disagree, this kit is wrong by definition.

Two things this kit does **not** do: it does not implement an editing engine
behind `rich-text-editor` (it styles a surface and a toolbar), and it does not
ship the drag gesture behind the bottom sheet's handle (it ships the
affordance). Both are noted in the gallery.
