Editorial Correspondence

Icon

Graphic symbol indicating the purpose of an interface element.

Image

Element for embedding images.

Avatar

Graphical representation of a user: photo, illustration, or initials.

Badge

Small label near a larger element showing status, property, or metadata.

Heading

Title or caption introducing a section.

Label

Text label for a form input.

Link

Reference to a resource, internal or external.

List

Grouping of related items: unordered, ordered, or description (key/value).

Progress bar

Horizontal bar showing completion of a long-running task, updated continuously.

Quote

A quotation from a person or source, or a highlighted passage of the current document.

Separator

A line between two elements or groups.

Skeleton

Placeholder layout for content that has not loaded, usually grey boxes.

Spinner

Indicator that a process is running and the interface is not ready yet.

Stack

Layout wrapper that puts a consistent gap between children.

Visually hidden

Text that is invisible on screen but read by assistive technology.

Button

Triggers an action such as submitting a form or revealing an interface component.

Checkbox

Binary choice alone, or multi-select within a group.

Fieldset

Wrapper for related form fields.

Text input

Form control accepting a single line of text.

Date input

Text entry of a date, often split into day/month/year fields.

File

Representation of a file, such as an uploaded attachment or a downloadable PDF.

File upload

Lets users upload a file from their device.

Progress indicator

Shows a user's progress through a series of discrete steps.

Radio button

Selects exactly one option from a predefined list.

Rating

Displays and/or sets a star rating for an item.

Search input

Lets users find content by entering a search term.

Select

Form input that shows the current value collapsed and a list of options expanded.

Skip link

In-page link that jumps keyboard users past repeated navigation.

Slider

Chooses a value within a preset range.

Stepper

Edits a numeric value with decrement and increment buttons.

Textarea

Form control for multi-line text.

Toggle

Switches between two states, usually on and off, applying immediately.

Accordion

Vertical stack of headings that expand to reveal further content.

Alert

Informs the user of important changes in a prominent, in-flow way.

Breadcrumbs

Links showing where the current page sits in the hierarchy.

Button group

Wrapper for multiple related buttons.

Card

Container for content representing a single entity: a contact, article, or task.

Empty state

Tells the user there is no data in this view, usually with an alternative action.

Form

Grouping of input controls that submits information.

Navigation

Container for navigation links, to other pages or within the page.

Pagination

Navigates between pages of a split-up result set.

Segmented control

Hybrid of button group, radio group, and tabs: switches between options or views.

Table

Displays large amounts of data in rows and columns; a data table when it also sorts and filters.

Tabs

Navigates between panels, fitting more into a smaller space.

Tree view

Displays nested hierarchical information such as a directory structure.

Popover

Pops up from another element over other content; unlike a tooltip it is click-triggered and can hold interactive elements.

Color picker

Input for choosing a color.

Combobox

Select-like input with free text to filter options.

Datepicker

Calendar view for choosing a date.

Modal

Appears over other content and requires interaction before returning underneath.

Drawer

Panel sliding in from an edge of the screen.

Dropdown menu

Menu of actions or navigation options revealed by a button; unlike a select it is not a form input.

Toast

Alert that appears in a layer above content, like a push notification.

Tooltip

Shows a short description of an element, usually on hover or focus.

Carousel

Displays multiple slides of content, navigated by swipe, scroll, or buttons.

Footer

Bottom-of-page region with copyright, legal information, and related links.

Header

Appears across the top of every page; usually holds the site name and main navigation.

Hero

Large banner near the top of a page, often with a full-width image.

Rich text editor

Edits formatted content, usually through a WYSIWYG interface.

Video

Displays video content, usually with playback controls.
